padelpy2 documentation

padelpy2 is a Python bridge to the stock PaDEL-Descriptor Java application: typed descriptor and fingerprint catalogs, an RDKit-native Calculator, pandas DataFrame results, and a low-level padeldescriptor CLI surface shared with padelpy.

Start with Installation and Quickstart. To choose between padelpy and padelpy2, read When to use which package. Migrating from padelpy: Migrating from padelpy.

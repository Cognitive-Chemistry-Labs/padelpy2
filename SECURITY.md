# Security policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |

## Reporting a vulnerability

If you discover a security issue in padelpy2, please email
**travis@cognichem.com** rather than opening a public GitHub issue.

Include a description of the issue, steps to reproduce if possible, and any
relevant logs or environment details. You should receive an acknowledgment
within a few business days. Please allow time for assessment and a fix before
any public disclosure.

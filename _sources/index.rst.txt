padelpy2 documentation
======================

**padelpy2** is a Python bridge to the **stock** PaDEL-Descriptor Java
application: typed descriptor and fingerprint catalogs, an RDKit-native
``Calculator``, ``pandas`` DataFrame results, and a low-level
``padeldescriptor`` CLI surface shared with padelpy.

Start with :doc:`installation` and :doc:`quickstart`. To choose between padelpy
and padelpy2, read :doc:`when_to_use`. Migrating from padelpy: :doc:`migration`.
